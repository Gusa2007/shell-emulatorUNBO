# Эмулятор командной оболочки (вариант 3)

GUI-эмулятор языка оболочки UNIX-подобной ОС на Python (tkinter).
Работа эмулятора максимально похожа на работу в терминале: приглашение
`user@host:/$`, история ввода стрелками, сообщения об ошибках в стиле bash.

## Этап 1. REPL

* окно на tkinter, заголовок строится из данных реальной ОС:
  `Эмулятор - [username@hostname]`;
* парсер командной строки с поддержкой кавычек `'...'`, `"..."`
  и экранирования `\`;
* сообщения об ошибках: неизвестная команда, неверные аргументы,
  незакрытая кавычка;
* команды-заглушки `ls`, `cd` (выводят имя и аргументы);
* команда `exit [код]`.

## Структура

```
src/main.py              точка входа
src/emulator/parser.py   разбор строки на слова
src/emulator/shell.py    ядро: выполнение команд
src/emulator/commands.py встроенные команды
src/emulator/gui.py      окно терминала
src/emulator/system.py   данные реальной ОС
tests/                   тесты pytest
```

## Запуск и тесты

Требуется Python 3.8+ с tkinter.

```sh
./run.sh          # Linux / macOS
run.bat           # Windows
make test         # тесты (нужен pytest)
make lint         # проверка стиля (нужен flake8)
```

## Пример

```
user@host:/$ ls -l "My Documents"
ls: аргументы ['-l', 'My Documents']
user@host:/$ cd a b
cd: слишком много аргументов
user@host:/$ foo
emu: foo: команда не найдена
user@host:/$ ls "abc
emu: синтаксическая ошибка: незакрытая двойная кавычка
```
